# Cookie Clicker

**쿠키를 클릭해서 자동 생산 공장을 세우는 인크리멘털 게임. 처음엔 클릭 한 방, 나중엔 초당 수백만 쿠키! 강화/스킬트리/프레스티지 시스템으로 무한 성장.**

자체 서버 (Next.js + PostgreSQL) 기반으로 구축된 웹 클리커 게임.

## Links
- 🌐 **Play**: https://cookieclicker.olivilo.shop

## Tech Stack
- Next.js 16 (TypeScript)
- Prisma + PostgreSQL
- Cookie Clicker Game Engine (Custom)
- Enhancement / Prestige System

## AI 활용

**구현은 AI 코딩 에이전트가 담당**했고, 기획과 검증을 직접 했습니다.
에이전트 작업 세션 기록(`.superpowers/`)을 그대로 남겨 두어,
어느 부분이 에이전트 산출물인지 추적할 수 있습니다.
