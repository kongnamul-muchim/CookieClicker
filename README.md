# Cookie Clicker

**쿠키를 클릭해서 자동 생산 공장을 세우는 인크리멘털 게임. 처음엔 클릭 한 방, 나중엔 초당 수백만 쿠키! 강화/스킬트리/프레스티지 시스템으로 무한 성장.**

자체 서버 (Next.js + PostgreSQL) 기반으로 구축된 웹 클리커 게임.
